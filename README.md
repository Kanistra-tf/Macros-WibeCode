# Macros-WibeCode
Макрос-рекордер с визуальным интерфейсом для Roblox GPO (и не только).
Записывает нажатия клавиши движения мыши, а потом воспроизводит их — по кругу,
с настраиваемой скоростью и рандомной задержкой.

Чтобы скачать перейдите - **Releases\GPO_Macros.rar**

## ✨ Возможности

- 🎥 **Запись макросов** — клавиатура и (опционально) мышь
- 📁 **Несколько макросов** — записывай разные маршруты, переключайся в один клик
- 🔁 **Циклы** — воспроизведение N раз или бесконечно (`0`)
- ⏩ **Скорость** — ускорение/замедление в N раз
- ⌨️ **Глобальные хоткеи** — F9/F10/F8 (настраиваются) работают даже свёрнутым
- 🎲 **Рандомная задержка** — добавляет от X до Y секунд к каждому действию (обход детекторов)
- 🖼 **Свой фон** — любая картинка, регулируемое затемнение
- 🌌 **Стеклянный неоновый UI** — полупрозрачные панели в стиле cyberpunk

Приложение было создано при помощи нейросети **DeepSeek**
